# PersonalFinProject
The final personal project for my financial data analysis class

This project works by generating LLM analysis of stock data using identical prompts
and comparing the rate of different responces. The aim of this research is to show
the probability of changing LLM-generated recommendations for better operational
transparency.

To view the flask dashboard, run display_results.py and go to the server printed.
To regenerate the results used in the visualizations, run get_analysis.py.
Getting the updated results will take some time. This is normal.
